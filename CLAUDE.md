This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Build & Run

Out-of-source CMake build, already configured in `build/`:

```bash
cd build && make            # build both targets
./pinnacleSets --help       # see CLI options
./test_graph                # run unit tests
ctest                       # run tests via CTest
```

To rebuild from scratch:
```bash
cd build && cmake .. && make
```

The binary must be run from `build/` — paths to graph files are hardcoded as `../graphs/simple_connected_graphs/...`.

## CLI Usage

```bash
./pinnacleSets -s 5          # compute edge-removal stats for all 5-vertex graphs
./pinnacleSets -s 1-9        # compute stats for graphs of size 1 through 9
./pinnacleSets -s 7 --force  # delete existing stats file and recompute from scratch
./pinnacleSets -p "Bw"       # print adjacency matrix of a graph6-encoded graph
```

Stats output is written to `graphs/simple_connected_graphs/graphNc_stats.csv`. Processing is resumable — if the stats file already exists, it picks up where it left off.

## Architecture

This is a C++20 combinatorics research tool studying **pinnacle sets** of graphs: given a labeling of vertices with distinct integers 1..n, a vertex is a *pinnacle* if its label is greater than all its neighbors' labels. The project asks how edge removal affects the count of valid labelings for a given pinnacle set.

### Key files

- **`src/graph.hpp`** — The entire `Graph` class lives here (header-only). This is the core of the project. Adjacency is stored as `std::vector<uint64_t>` bitmasks (bit j set in `adjMatrix[i]` ↔ edge i–j exists), limiting graphs to 64 vertices.
- **`src/main.cpp`** — CLI front-end; the main computational pipeline is `Graph::getGraphStatsFast`.
- **`include/CompleteGraph.h` / `src/CompleteGraph.cpp`** — Older, slower implementation using `std::vector<std::vector<int>>` edge lists; kept for comparison/validation.
- **`include/permutations.h` / `src/permutations.cpp`** — Utility class for permutation combinatorics (superpermutations, bipartite pinnacle sets). Mostly independent of `Graph`.
- **`src/test_graph.cpp`** — Unit tests for `Graph`; also serves as usage examples.

### Graph class internals

- Labelings are enumerated via **Heap's algorithm** (`countHeapPermutationsInner`). Pinnacle validity is checked at each leaf using bitmask operations (`isValidLabelingFast`).
- Admissible pinnacle sets are found by iterating over independent sets of the required size (`getIndependentSets`) and checking a "safe" assignment. Independent sets of size k are generated by backtracking with bit-AND pruning.
- `getGraphStatsFast` is multithreaded: workers pick tasks atomically from the graph6 file, compute stats, then a priority queue serializes writes to the CSV in order.

### Data format

Graph files use **graph6 encoding** (standard format from Brendan McKay's nauty/traces). Files `graphNc.g6` contain all simple connected graphs on N vertices. `decodeGraphG6` handles the three-length variants (1-byte, 4-byte, 8-byte vertex count).

### Stats CSV format

Each output line: `<graph6_string>,<#decreased>,<#same>,<#increased>` — for each admissible pinnacle set and each edge, whether removing that edge decreased, kept the same, or increased the number of valid labelings.
