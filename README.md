# Pinnacle Sets

A C++20 combinatorics research tool for studying **pinnacle sets** of graphs and how
**edge removal** affects the number of vertex labelings that realize a given pinnacle set.

## Background

Take a graph *G* on *n* vertices and label its vertices with the distinct integers
1, 2, …, *n* (one label per vertex). A vertex is a **pinnacle** if its label is strictly
greater than the labels of all of its neighbors. The set of labels sitting on pinnacle
vertices is the **pinnacle set** of that labeling.

A given pinnacle set *P* can usually be realized by many different labelings. A set is
**admissible** for *G* if at least one labeling produces exactly *P* as its pinnacle set.
Because two adjacent vertices can never both be pinnacles, the pinnacle vertices always
form an *independent set* — this is what makes the search tractable.

The central research question this tool explores:

> Given a graph *G* and an admissible pinnacle set *P*, if we remove a single edge from *G*,
> does the number of labelings realizing *P* **increase**, **decrease**, or **stay the same**?

For every graph of a given size, and every admissible pinnacle set on it, the tool removes
each edge in turn and tallies which of the three outcomes occurs.

## Features

- **Edge-removal statistics** over *all* simple connected graphs of a given size (or a range
  of sizes), reading standard [graph6](https://users.cecs.anu.edu.au/~bdm/data/formats.html)
  files. For each admissible pinnacle set and each edge, it records whether removal decreased,
  preserved, or increased the labeling count.
- **Fast labeling counter** using Heap's algorithm to enumerate all *n*! labelings, with
  pinnacle validity checked via bitmask operations. A single traversal histograms the pinnacle
  set of every labeling at once, so counts for *all* pinnacle sets come from one pass.
- **Admissible pinnacle set enumeration** by iterating over independent sets of the required
  size (generated by backtracking with bit-AND pruning) and checking a safe assignment.
- **Multithreaded, resumable processing**: worker threads claim graphs atomically from the g6
  file; a priority queue serializes CSV writes in input order. If the stats file already exists,
  processing picks up where it left off.
- **Live progress display** (TUI) when run in an interactive terminal, with a `--no-tui` fallback
  that emits clean, escape-free logs for redirection to a file or pipe.
- **Path-graph tables**: prints a table of valid-labeling counts for path graphs *P_n* under
  contiguous pinnacle sets, formatted to mirror the tables in the accompanying paper.
- **Graph inspection**: decode and print the adjacency matrix of any graph6-encoded graph.

## Build

Out-of-source CMake build (already configured in `build/`):

```bash
cd build && make            # build the pinnacleSets target
./pinnacleSets --help       # see CLI options
```

To reconfigure from scratch:

```bash
cd build && cmake .. && make
```

Requires a C++20 compiler and CMake ≥ 3.15. The binary is linked statically (no shared-library
dependencies). **Run it from `build/`** — the graph-file paths are relative
(`../graphs/simple_connected_graphs/...`).

## Usage

```bash
./pinnacleSets -s 5             # edge-removal stats for all 5-vertex graphs
./pinnacleSets -s 1-9           # stats for graphs of size 1 through 9
./pinnacleSets -s 7 --force     # delete existing stats file and recompute from scratch
./pinnacleSets -s 6 --extra     # also log extra per-pinnacle-set info
./pinnacleSets -s 6 --no-tui    # plain log output (no live progress display)
./pinnacleSets -p "Bw"          # print the adjacency matrix of a graph6-encoded graph
./pinnacleSets -pg 9            # print path-graph labeling tables for P_n, n <= 9
```

| Option | Description |
| --- | --- |
| `-h`, `--help` | Show usage |
| `-s`, `--stats <range>` | Compute edge-removal stats for graphs of the given size(s); `<range>` is `N` or `N-M` |
| `-p`, `--print <g6>` | Print the adjacency matrix of a graph6-encoded graph |
| `-pg`, `--path_graph <size>` | Print labeling tables for all path graphs `P_n`, `n <= size` |
| `--force` | Delete any existing stats file(s) and recalculate from scratch |
| `--extra` | Log extra info about each pinnacle set |
| `--no-tui` | Disable the live progress display |

## Data

Input graphs use **graph6** encoding — the standard format from Brendan McKay's
[nauty/traces](https://users.cecs.anu.edu.au/~bdm/nauty/). The files
`graphs/simple_connected_graphs/graphs/graphNc.g6` contain every simple connected graph on
*N* vertices.

Stats are written to `graphs/simple_connected_graphs/stats/graphNc_stats.csv`. Each line is:

```
<graph6_string>,<#decreased>,<#same>,<#increased>
```

aggregating, over all admissible pinnacle sets and all edges, how edge removal changed the
number of valid labelings.

## Project layout

| Path | Purpose |
| --- | --- |
| `src/graph.hpp` | Header-only `Graph` class — the core of the project. Adjacency is stored as `std::vector<uint64_t>` bitmasks (limiting graphs to 64 vertices). |
| `src/main.cpp` | CLI front-end; the main pipeline is `Graph::getGraphStatsFast`. |
| `src/tui.hpp` | Live terminal progress display. |
| `include/CompleteGraph.h`, `src/CompleteGraph.cpp` | Older, slower edge-list implementation, kept for comparison/validation. |
| `include/permutations.h`, `src/permutations.cpp` | Permutation-combinatorics utilities (superpermutations, bipartite pinnacle sets); mostly independent of `Graph`. |
